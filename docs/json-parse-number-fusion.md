# JSON.parseAsync 数字扫描与转换融合：Mac ARM64 验证

验证日期：2026-10-25。基线为 `96891ef142380cd1b3387b043c4dcb7131fb054a`，已经包含上轮 Mac 解析优化和本地提交的 JSON.clone。本报告的降低比例是相对该基线的新增收益。

## 实现范围

保留后台解析器的融合路径：校验数字语法时累积原生有效数字及十进制指数。同步解析候选未通过控制组门槛，全部撤回；src/json/json-parser.cc 和 json-parser.h 与基线逐字节一致。累计至多 15 位数字、显式指数不超过 3 位、合成指数位于 [-22, 22] 时直接转换；两个操作数都可由 binary64 精确表示，一次乘除完成舍入。负号在转换后应用，保留 -0。超出范围仍调用原 StringToDouble；前导/尾随零计入当前保守位数上限。

这一范围来自既有 DoubleStrtod 的精确幂路径，对 x87/模拟器的非零指数缩放保持回退；指数为零的精确整数转换继续保留。同步解析维持基线；错误语法、位置、reviver 原始文本均由原解析流程处理。

没有改变公开 API、12 字节中间记录、数组构建策略、输入所有权、worker 发布方式或 2 ms 前台软预算。后台长输入的取消检查继续保留。

## 测量方法

- Apple M1 Pro / macOS ARM64，Release -O3，无 LTO/PGO，沿用 out/host/args.gn。
- 27 类输入，每类 1/4 个任务，固定 4 个 worker。四轮相邻独立进程配对，逐轮反转基线/候选顺序；每进程预热 2 次，每种模式测量 15 次。
- 输入准备、显式计时前 GC 和结果校验不计入 API 延迟；计时内自然 GC 保留。四任务值为批次完成时间。
- 绝对值为各进程中位数的中位数；降低百分比为 1 - 新版/基线。另保存每轮配对变化。系统未锁核，负载记录随每个进程保存。
- 最终 512 个进程、15360 个计时批次、108 个比较项。汇总与配对变化中位数均未出现 >=5% 的回退；目标异步数值场景均达到 >=10%，各轮方向一致。
- fused/final 的通用同步融合版本在纯 Smi 记录上回退约 6%–8%，split 拆分版本仍有同样回退。array-fast/final2 虽解决该项，却在密集转义/混合字符串上回退约 12%–28%。这些同步候选均撤回。async-only 对照及最终 accepted 保留后台改动；本节只汇总与最终 d8 哈希相同的样本，所有旧样本独立保存。
